# Bicycle Shop Sales Dashboard – Power BI

## Project Overview

This project presents an interactive Power BI dashboard designed to analyze the sales performance of a bicycle shop.

The dashboard provides an overview of key business metrics and allows users to explore sales data through interactive visualizations and filters.

## Key Performance Indicators

* Total Sales
* Profit (%)
* Profit ($)
* Units Sold
* Top Country

## Visualizations

The dashboard includes:

* Pie Chart
* Donut Chart
* Stacked Column Chart
* Clustered Bar Chart
* Line Chart
* KPI Cards
* Interactive Filters

## Tools Used

* Microsoft Power BI
* Power Query
* DAX
